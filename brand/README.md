# Utah AI Safety Hub logo kit

Both marks are drawn from real elevation data for Mount Timpanogos (AWS Terrain Tiles, built mainly from USGS 3DEP data), the same source as the contours on the website.

## The two marks

- **Map mark** (`uash-mark-*`): contour lines around the Timpanogos summit, every 100 m. The main logo. Use it at about 48 px and larger.
- **Tile** (`uash-tile-*`): a solid square with five heavy contour lines. Use it wherever the logo is small or needs to be a square: favicons, social media avatars, app icons, stickers. The `-small` files have heavier lines for 16–48 px.

## Colors

| Name | Hex | Use the files ending in |
|---|---|---|
| Pine | `#3d6b4f` | `-pine` on light backgrounds |
| Paper | `#f7f8f4` | `-paper` on pine green or photos |
| Mint | `#82bf96` | `-mint` on dark backgrounds (`#141813`) |

## Files

| File | What it is |
|---|---|
| `svg/uash-logo-horizontal-*.svg` | Map mark beside the name. Default logo for documents and slides. |
| `svg/uash-logo-horizontal-tile-*.svg` | Tile beside the name. For tight spaces such as headers and email signatures. |
| `svg/uash-logo-stacked-*.svg` | Map mark above the name in spaced capitals. For posters, title slides, merch. |
| `svg/uash-mark-*.svg`, `svg/uash-tile-*.svg` | The marks on their own. |
| `png/` | The same files as PNGs with transparent backgrounds (tiles are solid squares). Marks at 512, 1024, and 2048 px; tiles at 512 and 1024 px; small tile at 16–192 px. |
| `png/og-image.png` | 1200 × 630 link-preview image. |

Prefer the SVGs: they stay sharp at any size. The name is converted to outlines, so the files look the same on computers without the fonts. The fonts are Newsreader (the name) and Geist (spaced capitals), both free under the SIL Open Font License.

## Don'ts

- Don't recolor the marks outside the three colors above, stretch them, or add effects.
- Don't use the map mark below about 48 px; use the tile instead.
- Leave clear space around the logo of at least a quarter of the mark's height.
